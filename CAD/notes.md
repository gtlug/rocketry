These CAD files should be in ready to print format, but your milage may vary... 

3 parts make up the complete Nose Cone assembly.

    1x Inside Sled.
  
    1x Bottom Piece.
  
    1x Top Part.

The current design is version 4 REV F. Versions 1 through 3 changed the way the nose cone assembly separated and how the PCB mounted inside the nose cone.

I read some old papers from NASA when they were using the Apollo missions to go to the moon, and abstracted some basic design philosophies for the geometry.
